# M7.5 crafting bench decisions

Decision rows for the crafting bench pass (merge into docs/DECISIONS.md at the end of M7.5).

| Date | Question | Decision | Reason |
|---|---|---|---|
| 2026-10-25 | How does "pick a currency, then click items" avoid spending by accident? | A currency is only armed once the player picks it in the bench's wallet (`craftArmed`). The wallet starts with Weaver's Knot as the current currency, but until one is picked a click on an item only selects it. Clicking the armed currency again puts it away. Leaving the bench disarms. A valid item click while armed uses the currency at once and the currency stays armed | `craftCurrency` has a default and the bag's Ctrl-click sets `craftTarget` before opening the bench; spending the default currency on either would be a nasty surprise. The explicit Use button still works for the selected item |
| 2026-10-25 | Which crafts ask for confirmation? | The first craft on a Rare asks, per item and per hero (a new game or a loaded save asks again). Chaos Skein asks every time on a Rare. Uniques would ask too, but the sim refuses every craft on a Unique, so they are only dimmed ("Uniques can't be changed"). The dialog has a "Don't ask again this session" tick that stops all confirmations until the page reloads. Normal and Magic items never ask | Matches the brief; Chaos Skein throws away every affix, so it is the one craft that asks each time |
| 2026-10-25 | What is a "changed" affix in the before/after? | Lines are paired by affix id, tier and rolled value, one for one. A line left without a pair in the old list is removed (red, struck through); one left without a pair in the new list is new (green). A reroll that lands on the same affix, tier and value shows as unchanged | A rolled value is part of what the player is chasing, so a different value is a different line |
| 2026-10-25 | Outcome wording | A rarity change reads "Magic → Rare · 5 affixes"; Spool of Change and Chaos Skein read "rerolled N affixes" (N is the new count); Golden Needle "added 1 affix"; Unpick "removed 1 affix"; Rune Polish "Quality 3% → 4%". A craft that renames the item (Loom Shuttle) shows "Wool Hood → Dusk Crown" under it | Short, and uses the wording of the brief |
| 2026-10-25 | Where does the last result live when the selection moves? | `craftResult` stays until the next craft, whatever is selected. With the crafted item selected it replaces the flat affix list (its After column carries tier and range); with another item selected the bench shows the other item's list plus a "Last craft: ..., Show" line | Keeps the result visible without two copies of the same item on screen |
| 2026-10-25 | What does the hover text of a currency say? | Its `text` from data/currency.ts, then only what the data tables hold: Magic affix counts and the both-sides chance (data/affixes.ts), the Rare affix count weights as percentages (data/currency.ts rareAffixCount), the Rare slot limits, the share of currency drops from `dropWeight`, the Spindlewright price (data/hearth.ts), and the sim's own rules (item level gates tiers, Uniques can't change, a currency is only used up when the craft works, Unpick picks at random). No other odds | "Don't invent odds" |
| 2026-10-25 | One-line wallet rules | A UI table in src/ui/craft/craftRules.ts (`shortRule`): "Normal → Magic", "Normal → Rare", "Reroll a Magic item", "Reroll a Rare item", "Add an affix to a Rare", "Remove one affix", "+1% rune quality (max 20%)". The full sentence stays `currencies[id].text` | Short labels are presentation, not game data |
| 2026-10-25 | The R key for "Use again" | A capture-phase window listener while the bench is mounted: R repeats the last craft and stops the event, ignored in text fields and while the confirmation is open. Checked conflicts: R is Cast 5 in play (input.ts), but taps are dropped while the sim is paused in a menu; the lab room's R (labHint.tsx) would also fire in the lab room, so the bench swallows R first; no menu uses R | The brief asked for R unless it conflicts; stopping the event removes the one conflict |
| 2026-10-25 | When is the Spindlewright link offered? | Under the wallet (and, on the narrow layout, in the bench when the picked stack is empty): at the lit Hearth, a "Buy from the Spindlewright" button that sets `hearthTab` to `spindlewright` and opens the Hearth menu; elsewhere once the Hearth is lit, a hint that the Spindlewright sells these at the Hearth; before it is lit, nothing. The price of the picked currency shows with the player's Scrap if it is short | Buying works only inside the Hearth (`hearthGateError`), so the link would fail elsewhere |
| 2026-10-25 | Menu text size on the narrow layout | The bench raises its own `--u` to 7.2 px under 760 px wide (the menu default is 4.4 px) so its smallest text is about 11 px; the bench's smallest text is 1.55 × `--u` (11.2 px at 720p and on phones). The bench is one column there: wallet, then the bench panel (sticky at the top while the list scrolls under it, at most 60% of the screen), then the list | The shared menu `--u` made secondary text about 6 px. Only the bench is changed; other menus keep the shared value |
| 2026-10-25 | Item art in the bench | `ItemArt` and `CurrencyArt` (src/ui/items/itemArt.tsx) fill a `.cr-art` box the bench sizes. The bench does not set `.ia-*` styles | The art contract: callers size the container, the art agent owns the picture |
| 2026-10-25 | Affix lines in the bench | `src/ui/craft/affixLine.ts` builds on the shared `affixParts` and `rangeText` (src/ui/items/affixText.ts) and adds the diff key (affix, tier, value), the bench's hover text and a fallback for unknown ids. Kept (locked) items show a padlock in the list; currencies still apply to them, only salvage is blocked | One source for tier and range text; locking does not change what crafting may do |
