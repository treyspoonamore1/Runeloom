# pt8hits decisions (playtest 8: reduced hits, hints, Bellshell readability, long notes)

| Date | Question | Decision | Reason |
|---|---|---|---|
| 2026-10-27 | Which reductions mark a hit as "reduced"? | Only target states: Shelled (any `chemistry.bell` enemy whose shell isn't rung open: Bellshell 90%, Old Bellwether 80%) and the Glasswater Coil Submerged (75% / 90%). Elemental resistances never count. | No simple uniform rule for resistances: the Coil resists 75% Storm everywhere, and greying every resisted hit would drown the signal the playtest asked for (a state you can change). |
| 2026-10-27 | How does the sim say why? | `'hit'` events from `applyHit` on an enemy carry an optional `reduced: 'shelled' \| 'submerged'` (`actors/chemistry.ts reducedBy`), set only when present so other hit events are unchanged. `dealDirectDamage` (falls, gas life loss) never carries it: those ignore multipliers. | Events are output only: `state.events` is not hashed (hashState.ts), so the state hash and replays are unaffected. |
| 2026-10-27 | Where does "already shown" live for the hints? | UI side, once per page session: one `ReducedHitHints` watcher in the adventure HUD (src/ui/adventure/reducedHints.ts). Not saved in hero flags. | Simplest; the sim, saves, the state hash and replays never see it. A reload can show a hint once more, which is harmless for a teaching line. |
| 2026-10-27 | Where do the hint thresholds go? | `data/tuning.ts hints` (reducedHits 5, windowSeconds 8 of sim time), as asked, so they show in the F2 tuning panel. The toast's on-screen seconds (7) are presentation and live in `data/ui.ts uiTuning.hintToastSeconds`; the texts in `data/ui.ts reducedHints`. | tuning.ts is cloned into GameState and stored in replays; the sim never reads `hints`, and cloneTuning fills it in for old replays, so nothing changes there. |
| 2026-10-27 | How do hints show? | A toast (kind 'hint') with its own icon (a brass shell with a small shield; deep water), a title line and a wrapping second line, kept 7 s. Only the player's own hits count. | The toast column is the existing small-note UI; the center banner is for room names and boss cards. |
