# M7 playtest starts: decisions

| Date       | Question                                              | Decision                                                                                                                                                                                                                                                    | Reason                                                                                                     |
| ---------- | ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 2026-10-25 | Where do the playtest buttons live on the title?      | A "Playtest starts" section in the main menu, shown whenever dev scenes show (`scenes` not null), two columns on wide screens, one on phones.                                                                                                               | One click from the title; the Sandbox scenes view stays for scenes only.                                   |
| 2026-10-25 | How are the saves produced?                           | `npm run sim -- --playtest-saves [--seed 1] [--tier 7] [--out dir]` (tools/lib/playtestSaves.ts), seed 1. Files are committed in data/playtest/.                                                                                                            | Deterministic bots, so the files are reproducible; committed so a build needs no sim run.                  |
| 2026-10-25 | What does "stand at K10's Loom Stone" mean in a save? | The generator calls `restAtStone` before `makeSave` (player on the stone, full life). Loading enters K10 at the respawn stone, which `createAdventure` places the player at since the Warden is dead.                                                       | The save keeps only world state, not position; the test checks `loomStoneHere` after load.                 |
| 2026-10-25 | How does the progression sim stop at tier 7?          | New `onEnd(state, result)` option on `runProgression`, with `rekindles: 0` and `stopAtTier: 7`. The loop stops after the first rift that makes `riftTier` 7 and the bot is home in the hub, so no rift is open, expeditions are out and Embers are unspent. | `stopAtTier` already existed but needs `rekindles: 0` to end the run; only the state hand-off was missing. |
| 2026-10-25 | What is "tier 7"?                                     | `hero.riftTier` is the best tier completed, so 7 means tier 7 is cleared and tier 8 (Rekindle's unlock tier) is next. The save holds a tier 7 sigil.                                                                                                        | Matches "Clear tier 8 to unlock Rekindle".                                                                 |
| 2026-10-25 | Autosave overwrite?                                   | If an autosave exists, a confirm view (`confirmPlaytest`) is shown like `confirmNew`; otherwise the start loads at once.                                                                                                                                    | Same rule as New Game.                                                                                     |
| 2026-10-25 | Validation?                                           | `npm run validate` parses every `data/playtest/*.json` with `parseSave` and checks its room exists.                                                                                                                                                         | Stale saves after a format change fail the check, not the playtest.                                        |
